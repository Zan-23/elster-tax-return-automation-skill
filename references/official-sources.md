# Official sources

Use these for tax-law facts, values and ELSTER guidance, and cite them next to every year-sensitive statement. Secondary sites (tax software blogs, news) may help you find an official source but are never the source.

| Source | Use for |
| --- | --- |
| https://www.gesetze-im-internet.de/estg/ | Income tax law: allowances, tariff (§ 32a), work expenses (§ 9), special expenses (§ 10), § 33, § 35a |
| https://www.gesetze-im-internet.de/ao_1977/ | Deadlines (§ 149), assessment periods (§ 169–171), late-filing surcharge (§ 152) |
| https://www.gesetze-im-internet.de/solzg_1995/ | Solidarity surcharge limits |
| https://www.bundesfinanzministerium.de | BMF letters (e.g. Reisekosten, Homeoffice, computer depreciation), official tax calculator, annual changes |
| https://www.bmf-steuerrechner.de | Official income tax calculator, for checking the estimate |
| https://esth.bundesfinanzministerium.de | Amtliches Einkommensteuer-Handbuch: law, guidelines (EStR), notes, by year |
| https://lsth.bundesfinanzministerium.de | Amtliches Lohnsteuer-Handbuch: LStR (e.g. telecom R 9.1), travel cost rules |
| https://www.elster.de | Forms, help texts, form instructions (Anleitungen), the FAQ, and the ELSTER Formularmanagement for line numbers |
| https://www.formulare-bfinv.de | Official PDF forms and instructions for each year, for line numbers and labels |
| https://www.arbeitsagentur.de | Certificates for wage-replacement benefits |
| State tax administration sites (e.g. finanzamt.bayern.de) | Operational detail and administrative flat rates not in federal sources |

## Rules

- Line numbers and labels change between years. Take them from the selected year's form or instructions, or from the ELSTER page itself during browser work, never from another year.
- If only a secondary source states a value, call it "administrative practice / not verified" and keep it out of hard claims.
- Note the date you checked each source in the year config.
